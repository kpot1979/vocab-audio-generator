# Полная инструкция: Установка, настройка и запуск генераторов аудио/видео уроков (`script.py` и `script_with_cach.py`)

Эта инструкция поможет вам подготовить окружение Windows, установить необходимые программы и библиотеки, а также разобраться, в чем разница между вашими двумя скриптами и как правильно их использовать.

---

## Шаг 1. Открытие терминала PowerShell и установка Python

### Как запустить PowerShell в Windows:
1. Нажмите комбинацию клавиш **`Win + R`**, введите `powershell` и нажмите **Enter**, либо откройте встроенный терминал прямо в VS Code с помощью комбинации **`Ctrl + ~`**.

### Почему именно Python 3.11?
Для работы скриптов используются сторонние библиотеки (`pandas`, `pydub`, `Pillow`, `mutagen` и др.), завязанные на скомпилированные бинарные модули. Версия **Python 3.11** гарантирует максимальную стабильность и беспроблемную установку всех пакетов.

Установите Python одной командой через терминал:
```bash
winget install Python.Python.3.11
```
*(После установки обязательно перезакройте и заново откройте терминал)*. Проверить успешность установки можно командой:
```bash
python --version
```

## Шаг 2. Установка программы FFmpeg через терминал
Для склейки аудиофрагментов, рекодировок и сборки итоговых видеофайлов используется утилита FFmpeg. Установите её через терминал командой:

```bash
winget install Gyan.FFmpeg
```
После завершения установки перезапустите терминал и проверьте доступность:
```bash
ffmpeg -version
```

## Шаг 3. Установка библиотек Python через терминал
Откройте папку со скриптами в терминале и установите все необходимые для работы пакетов зависимости одной командой:

```bash
pip install pandas gTTS pydub Pillow openpyxl mutagen requests kokoro-onnx soundfile
```
*(Пакет `mutagen` отвечает за запись текстовых тегов `USLT` внутрь MP3-файлов, а `requests` и `kokoro-onnx` понадобятся, если вы будете использовать облачный ElevenLabs или локальный Kokoro TTS).*

## Шаг 4. Подготовка конфигурации и Excel-файла

### 1. Файл ключей `config.py`
Убедитесь, что в корневой папке проекта рядом со скриптами создан файл **`config.py`**, в котором прописаны ваши API-ключи (если вы планируете использовать платные движки, такие как ElevenLabs или Azure):
```python
AZURE_SPEECH_KEY = "ваш_ключ_azure"
ELEVENLABS_API_KEY = "ваш_ключ_elevenlabs"
```

### 2. Подготовка Excel-файла (`vocabulary.xlsx`):
1. Создайте Excel-файл с именем **`vocabulary.xlsx`** (или измените имя в переменной `EXCEL_FILENAME` внутри скриптов) в одной папке со скриптами.
2. Стандартная структура колонок (настраивается через переменные `COL_LW`, `COL_RW`, `COL_DF`, `COL_RF`):
   * **Колонка 1 (A, `COL_LW`):** Слово на изучаемом языке (`learnWord`).
   * **Колонка 2 (B, `COL_RW`):** Перевод слова на родном языке (`nativeWord`).
   * **Колонка 3 (C, `COL_DF`):** Пример фразы на изучаемом языке (`learnPhrase`).
   * **Колонка 4 (D, `COL_RF`):** Перевод фразы на родном языке (`nativePhrase`).

## Шаг 5. Разница между нашими двумя файлами

В вашем проекте предусмотрено два независимых скрипта, которые используют **единый алгоритм расчета точных таймкодов** (на базе физического измерения длительности через `pydub` и перекодировки `libmp3lame`), но решают разные задачи по хранению аудиофайлов:

### 1. `script.py` (Режим без кэширования с полной очисткой)
* **Логика работы:** При каждом запуске скрипт полностью очищает папки с аудиоматериалами (`audio/<НазваниеЛиста>_<Движок>/`) и заново генерирует абсолютно все аудиофайлы для выбранного листа через выбранный движок (например, `gtts`, `elevenlabs` и др.).
* **Когда использовать:** Когда вам нужно гарантированно пересоздать всю озвучку с нуля (например, при изменении настроек голоса, скорости или исправлении ошибок в самом Excel-файле).

### 2. `script_with_cach.py` (Режим интеллектуального кэширования)
* **Логика работы:** Скрипт проверяет папку `audio/`. Если для изучаемого языка (`TTS_ENGINE_LEARN = "elevenlabs"`, например, для листа вроде *Schritte А1.2_9*) уже существуют папки вида `Schritte А1.2_9_ELEVENLABS` и подпапка `phrase_ELEVENLABS`, **существующие файлы не удаляются**.
* **Особенности сопоставления:** Скрипт автоматически учитывает, что исходные названия слов в таблице содержат спецсимволы, и сопоставляет их с помощью функции очистки (`sanitize_filename`). Если файл слова или фразы уже есть на диске, он берется из кэша **без повторного обращения к серверу ElevenLabs** (экономия лимитов API). Если какой-то файл отсутствует, он генерируется отдельно.
* **Консольный отчет:** По окончании работы скрипт выводит подробную статистику в терминал: сколько слов/фраз было загружено из кэша, а сколько сгенерировано заново (с перечислением конкретных элементов).
* **Когда использовать:** При работе с платными или лимитированными API (ElevenLabs, Azure), чтобы не тратить лимиты повторно на уже озвученные слова.

## Шаг 6. Настройка шаблона аудио и параметров (внутри файлов)

В верхней части обоих скриптов вы можете настроить шаблон воспроизведения (`TEMPLATE_STR`):

```python
TEMPLATE_STR = (
    "learnWord + shortPause + nativeWord + shortPause + learnWord + shortPause + learnWord + dynamicPause + "
    "learnPhrase + shortPause + nativePhrase + shortPause + learnPhrase + shortPause + learnPhrase + dynamicPause"
)
```

### Доступные блоки шаблона:
* `learnWord` — слово на изучаемом языке.
* `nativeWord` — перевод слова на родной язык.
* `learnPhrase` — фраза-пример на изучаемом языке.
* `nativePhrase` — перевод фразы на родной язык.
* `shortPause` — фиксированная короткая пауза (`SHORT_PAUSE_MS`).
* `dynamicPause` — интеллектуальная динамическая пауза, которая рассчитывается автоматически на основе длительности предыдущего аудиофрагмента (`PAUSE_MULTIPLIER` и `MANUAL_EXTRA_MS`).

## Шаг 7. Запуск скриптов

1. Откройте папку с проектом в VS Code или терминале PowerShell.
2. Запустите нужный вам скрипт командой:
   * Для запуска стандартного скрипта с полной генерацией:
     ```bash
     python script.py
     ```
   * Для запуска скрипта с использованием кэша (экономия API):
     ```bash
     python script_with_cach.py
     ```
3. В интерактивном меню терминала выберите нужный номер листа из вашего Excel-файла и нажмите **Enter**.

## Шаг 8. Результат работы

После завершения работы любого из скриптов в папке проекта будут созданы:
1. **`ИмяЛиста.mp3`** — готовый аудиоурок со всеми паузами.
2. **`ИмяЛиста.lrc`** — файл синхронизированных таймкодов (синхронизирован по реальной длительности аудиопотока без накопления сдвигов благодаря рекодировке `libmp3lame`).
3. **`ИмяЛиста.mp4`** — полноценный видеоролик для YouTube (разрешением 1920x1080) с визуальными карточками, адаптивным переносом строк и плавными переходами.
4. **Папки с кэшем/аудиоматериалами** (внутри директории `audio/`), содержащие отдельные MP3-файлы слов и фраз.
